# Fundamentos de la Web

Antes de desarrollar aplicaciones web, necesitamos comprender **cómo funciona la Web** y qué sucede cuando un usuario accede a una página.

Estudiaremos los elementos que intervienen en la comunicación entre un **cliente y un servidor**, desde las redes que los conectan hasta los protocolos que permiten intercambiar información.

::: objetivos Qué vamos a aprender
- Comprender cómo se comunican los equipos a través de una red.
- Diferenciar Internet de la World Wide Web.
- Identificar los principales protocolos y servicios de Internet.
- Entender el funcionamiento de HTTP y HTTPS.
- Reconocer el papel del navegador, el servidor web y las aplicaciones del servidor.
 :::

1. Crea un array de 15 notas inicializadas a `0`.
2. Asigna valores aleatorios entre `5` y `10`.
3. Muestra las notas y calcula el máximo, el mínimo y la media.
4. Crea otro array de 15 notas aleatorias entre `0` y `5`.
5. Combina ambos arrays y vuelve a calcular los valores estadísticos.
6. Recorre el resultado con `foreach` y con `reset()`, `current()`, `key()` y `next()`, mostrando claves y valores.
7. Busca la posición del primer `10` y comprueba si existen las notas `7` y `4`.
8. Ordena las notas de forma ascendente y descendente.
9. Elimina los valores repetidos.

**Condición:** utiliza las funciones de arrays estudiadas.

Disponemos de un array multidimensional `$artistas` que contiene información de artistas musicales y sus canciones.

1. Analiza la estructura del array, identificando sus claves, valores y niveles.
2. Explica qué partes son arrays indexados y cuáles son asociativos.
3. Recorre el array mostrando el nombre y las décadas de cada artista.
4. Muestra debajo de cada artista los títulos de sus canciones y sus enlaces.
5. Utiliza CSS para diferenciar visualmente los artistas y sus canciones.

**Datos:** utiliza el array `$artistas` proporcionado con el ejercicio.

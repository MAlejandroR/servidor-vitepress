tema: arrays

Crea una aplicación que permita identificar a los usuarios y contar sus accesos.

- Muestra un formulario para introducir el nombre de usuario.
- Utiliza un array asociativo cuya clave sea el nombre y cuyo valor sea el número de accesos.
- Cada vez que el usuario pulse el botón, incrementa su contador.
- Muestra los usuarios y sus accesos acumulados.

**Condición:** conserva los contadores entre envíos del formulario.
